# Pónifarm 🦄

Kawaii stílusú ponifarm weboldal, webfejlesztés beadandó (HTML, CSS, JavaScript, jQuery). Keretrendszert (pl. Bootstrap) nem használ.

## Oldalak

| Fájl | Tartalom |
|---|---|
| `index.html` | főoldal, bemutatkozás, számozott és pontozott lista |
| `ponies.html` | ponik táblázata, keresés és szűrés szín szerint |
| `adoption.html` | örökbefogadási űrlap ellenőrzéssel |
| `gallery.html` | képgaléria és linkek |

## Mappák

- `css/`: `style.css` (általános), `form.css` (űrlap)
- `js/`: `effects.js` (animációk, új elem), `ponies.js` (szűrés), `validation.js` (űrlap ellenőrzés)
- `img/`: saját készítésű SVG poni illusztrációk
- `docs/`: a dokumentáció fejezetei (Markdown) és a képernyőképek
- `bemutato/`: bemutató forgatókönyv és lehetséges kérdések
- `dokumentacio.docx`: a teljes dokumentáció Word formátumban

## Futtatás

Nincs szükség telepítésre, nyisd meg az `index.html`-t böngészőben. A jQuery az internetről (CDN) töltődik be, ezért a működéshez netkapcsolat kell.
